# Planning archive

Historical implementation plans, kept for the reasoning behind decisions rather than as
a description of the code. Each one describes the tree as it was on its own date, so
file paths, commands and dependency claims in here are often no longer true.

Where a later change contradicted a plan outright, the line is annotated in place with
**superseded `<date>`:** and what replaced it. Everything else is unmarked and unaudited.

For how the project actually works today, read `.claude/rules/` and the README.
